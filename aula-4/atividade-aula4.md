

## Processo 1 — Registro de pedidos

### Requisito 1
O sistema deve permitir que o vendedor cadastre um novo pedido.

**Fonte 1:** Entrevista com um vendedor.  
Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Formulário ou modelo de pedido já usado pela empresa.  
Fonte não humana, categoria documentação.

### Requisito 2
O sistema deve permitir informar os produtos e as quantidades de cada pedido.

**Fonte 1:** Entrevista com um vendedor.  
Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Observação de como uma venda é feita atualmente.  
Fonte humana, nível operacional, classe de usuário vendedor.

### Requisito 3
O sistema deve calcular o valor total do pedido.

**Fonte 1:** Entrevista com um vendedor.  
Fonte humana, nível operacional, classe de usuário vendedor.

**Fonte 2:** Tabela de preços dos produtos da empresa.  
Fonte não humana, categoria documentação.

## Processo 2 — Cadastro de produtos

### Requisito 1
O sistema deve permitir que o administrador cadastre novos produtos.

**Fonte 1:** Entrevista com o administrador.  
Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Lista de produtos já utilizada pela empresa.  
Fonte não humana, categoria documentação.

### Requisito 2
O sistema deve permitir alterar as informações de um produto.

**Fonte 1:** Entrevista com o administrador.  
Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Sistema ou planilha atual de cadastro de produtos.  
Fonte não humana, categoria sistema existente.

### Requisito 3
O sistema deve permitir remover um produto que não é mais vendido.

**Fonte 1:** Entrevista com o administrador.  
Fonte humana, nível operacional, classe de usuário administrador.

**Fonte 2:** Política da empresa sobre produtos fora de linha.  
Fonte não humana, categoria documentação.

## Processo 3 — Controle de estoque

### Requisito 1
O sistema deve mostrar a quantidade disponível de cada produto.

**Fonte 1:** Entrevista com um funcionário do estoque.  
Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Planilha ou sistema atual de controle de estoque.  
Fonte não humana, categoria sistema existente.

### Requisito 2
O sistema deve permitir registrar a entrada de produtos no estoque.

**Fonte 1:** Entrevista com um funcionário do estoque.  
Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Notas fiscais de entrada de mercadorias.  
Fonte não humana, categoria documentação.

### Requisito 3
O sistema deve permitir registrar a saída de produtos do estoque.

**Fonte 1:** Entrevista com um funcionário do estoque.  
Fonte humana, nível operacional, classe de usuário estoque.

**Fonte 2:** Registros de vendas e movimentações de estoque.  
Fonte não humana, categoria documentação.
